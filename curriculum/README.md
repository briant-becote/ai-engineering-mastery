# Curriculum roadmap and guided labs

The `AI_Engineering_Mastery_v2_GitHub_Reviews.xlsx` workbook is the 19-module, 88-week, 616-day **reference roadmap**. Scheduled dates are delivery targets, not proof of completed work or mastery.

## Guided Udemy integration

The approved [Udemy guided-lab map](udemy_course_map.yaml) specifies **46 supplemental guided lab assignments** tied to scheduled days. Each entry records its source course, named lecture(s), independent build quest, and intended GitHub evidence. The map complements the workbook's daily lesson topics; it does **not** replace mathematics-first instruction or require watching all paid videos.

- Modules M02–M04: mathematics and probability (probability purchase **deferred**; use free alternatives such as [Harvard Stat 110](https://stat110.hsites.harvard.edu/) until available).
- Modules M06–M07: PyTorch implementation, training, vision, experiment tracking, and a small Vision Transformer reproduction.
- Modules M11–M12: Ed Donner's Core LLM course for supervised fine-tuning, LoRA/QLoRA, and retrieval evaluation.
- Module M13: Eden Marco as the primary LangGraph/MCP path, with Ed Donner's [Agentic Track](https://github.com/ed-donner/agents) as comparative labs on Days **396, 398, 417 and 419**.
- Modules M16–M18: AI deployment, LLM/agent evaluation, and authorized AI security testing.

Named Udemy lecture titles and durations were transcribed from the learner-supplied course outlines. Course enrollments and lesson completions are **not** implied. Paid lesson content, course source archives, notebooks, datasets, and credentials must not be copied into this public repository unless specifically authorized by their licenses. Keep independently written implementations and permitted citations only.

## Learning state and reviews

[Learning state](../learning/state.yaml) and code/test/review evidence establish verified progress. A daily lesson is not a passed assessment. Follow the [review protocol](../docs/review_protocol.md) for weekly self-reviews, 14-day code reviews, 28-day deep reviews, and module mastery gates.

Use [the project setup guide](../setup/CHATGPT_PROJECT_SETUP.md) and [the automation context contract](../learning/automation_context_contract.md) for the interactive workflow. The scheduled task may read the YAML course map and repository files **only when access is actually available**.
