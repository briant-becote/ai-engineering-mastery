# Module and session handovers

Create a new, concise handover when moving to a new module or rolling over a lengthy chat. For example, `m02-linear-algebra-handoff.md`.

Use this template:

- Module / verified topic:
- Git commit or PR actually reviewed:
- Confirmed concepts mastered, with evidence:
- Failed or incomplete tests and their output:
- Important design decisions, with links:
- Known misconceptions or open questions:
- Specific next task (one or two):
- Relevant source links, chapter pointers:
- Facts that **must not** be assumed:

Target one screen, roughly 250–400 words; point to sources rather than pasting entire logs.
